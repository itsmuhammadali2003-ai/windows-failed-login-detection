Windows Failed-Login Detection Lab

Project Overview

This is a beginner cybersecurity project focused on investigating failed Windows login attempts, understanding security logs, and identifying patterns that may indicate password guessing.

Project Objectives

- Understand Windows Security Event ID 4625.
- Learn how to examine authentication events.
- Identify repeated failed login attempts in sample data.
- Document findings and recommend defensive actions.

Tools Used

- Windows Event Viewer
- GitHub
- CSV sample data
- Windows security documentation

Investigation Method

1. Learn the structure of Windows failed-login events.
2. Prepare safe, simulated authentication events.
3. Analyse the events for repeated failures.
4. Document the results and limitations.
5. Recommend security improvements.
